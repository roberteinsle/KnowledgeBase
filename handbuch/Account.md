# Account

Open your account via your avatar at the top right → **Account**.

## Profile picture

- **Upload:** PNG, JPG, WebP or GIF up to 1 MB. The picture is shown round, so a square picture works best. SVG is not allowed for security reasons.
- **Remove picture** goes back to the generated avatar.
- Without a picture the app shows your **initials on a coloured background** (e.g. "Erika Mustermann" → "EM"). The colour is derived from the name and stays the same.

The avatar appears in the header (also in the administration area), in the user list of the administration and next to "last changed by" on pages. Every signed-in user can see the avatars of other users.

## Name and language

- **Name:** shown as author of pages and in the activity log.
- **E-mail address:** only an administrator can change it.
- **Language:** German, English, French, Italian or Spanish; *Workspace default* uses the browser language or the default of the workspace.

## Security

**Passkeys and two-factor authentication** leads to the security page – see [Sign-in](Sign-in.md).
